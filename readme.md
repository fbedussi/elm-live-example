# Let's write the todo list in Elm

This is the companion repo for a workshop where we can learn how to code the todo list in elm.

## Getting started

Checkout the `start` branch

Install the dependencies with

```
npm install
```

start the dev server with

```
npm start
```

start coding in the `src/Main.elm` file.

The `development` branch contains a possible solution.
